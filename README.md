## Описание проекта
Программа реализует плавную анимацию трансформации геометрической фигуры из идеального круга в равносторонний треугольник и обратно. Преобразование точек рассчитывается в полярных координатах методом линейной интерполяции радиусов.

## Функциональные возможности
### Основной функционал
-  Плавная зацикленная анимация превращения фигуры
-  Расчет геометрии в реальном времени с помощью полярных координат
-  Кроссплатформенный графический интерфейс на базе Tkinter

### Дополнительный функционал
-  Пауза и возобновление анимации по нажатию на клавишу `Space`
-  Сброс анимации в исходное состояние (круг) по нажатию на клавишу `R`

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** macOS / Windows / Linux
- **Библиотеки:** Только стандартная библиотека Python (`tkinter`, `math`)

## Установка и запуск
### 1. Клонирование репозитория
```bash
git clone git@github.com:jam-kaz/animation_project_2.git
cd animation_project
```

### 2. Создание и активация виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
- `Space` — пауза / запуск анимации
- `R` — сброс анимации к состоянию круга
